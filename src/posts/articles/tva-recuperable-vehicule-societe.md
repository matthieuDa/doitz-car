# TVA Récupérable Véhicule de Société : Conditions et Calcul 2026

Si vous achetez un véhicule pour votre entreprise, la question de la **TVA récupérable** est cruciale : elle peut représenter plusieurs milliers d'euros. Mais les règles sont complexes et les pièges nombreux.

## Le principe : VP ≠ VU

La règle de base est simple, mais souvent mal comprise :

| Type de véhicule | TVA récupérable ? | Condition |
|---|---|---|
| **Véhicule utilitaire (VU)** | ✅ Oui, 100% | Carte grise CTTE ou VASP |
| **Véhicule particulier (VP)** | ❌ Non | Même usage 100% pro |
| **VP transformé en VU (DERIV VP)** | ✅ Oui | Transformation homologuée |
| **VP électrique** | ✅ Partiellement | Voir conditions spécifiques |

> **⚠️ Piège n°1** : Un SUV immatriculé en VP n'ouvre PAS droit à la récupération de TVA, même s'il est utilisé exclusivement pour le travail.

## Les 4 cas de récupération de TVA

### 1. Véhicules utilitaires (CTTE)

- **TVA 100% récupérable** sur l'achat ou les loyers
- Exemples : Kangoo, Berlingo, Trafic, Partner, Transit
- La TVA sur le carburant diesel/E85 est aussi récupérable

### 2. Véhicules DERIV VP

Un véhicule particulier **transformé** : banquette arrière retirée, homologation VASP ou CTTE.

- TVA récupérable après modification
- Coût de la transformation : 800 à 2 000 €
- ⚠️ Doit être homologué par la DREAL ou un centre agréé

### 3. Véhicules électriques

Depuis 2021, la TVA sur les **véhicules électriques** est **récupérable à 100%** même pour les VP, sous conditions :

- Location longue durée (LLD) ou LOA : TVA sur les loyers récupérable
- Achat : TVA récupérable si le véhicule est affecté à l'activité

> **💡 Bon plan** : Un Tesla Model 3 en LLD avec TVA récupérable revient à ~400€/mois net pour un professionnel.

### 4. TVA sur le carburant

| Carburant | VP | VU |
|---|---|---|
| Gazole / Diesel | 80% récupérable | 100% récupérable |
| Essence (depuis 2022) | 80% récupérable | 80% récupérable |
| Électricité | 100% récupérable | 100% récupérable |
| GPL / GNV | 100% récupérable | 100% récupérable |
| E85 | 80% récupérable | 100% récupérable |

## Calcul concret : combien vous économisez

**Exemple : Renault Kangoo Van - 25 000€ HT**

- TVA récupérée à l'achat : **5 000 €**
- TVA carburant (diesel, 15 000 km/an) : ~**600 €/an**
- Économie sur 4 ans : **7 400 €**

**Exemple : Peugeot 3008 VP - 36 000€ TTC**

- TVA récupérée : **0 €** (VP = non récupérable)
- Si le même budget sur un Peugeot Expert VU : **6 000 € récupérés**

## Les 5 erreurs à éviter

1. **Acheter un VP en pensant récupérer la TVA** — c'est la carte grise qui détermine le droit, pas l'usage
2. **Oublier de déclarer la TVA sur le carburant** — beaucoup de TPE/PME ne la réclament pas
3. **Négliger le DERIV VP** — la transformation est rentable dès 6 mois
4. **Confondre TVA récupérable et amortissement** — ce sont deux mécanismes distincts
5. **Importer un VU sans vérifier le quitus fiscal** — la TVA doit être payée en France

## Récupération TVA pour un véhicule importé

Si vous achetez un véhicule professionnel en Europe :

- **Neuf (< 6 mois ou < 6 000 km)** : TVA française à payer, puis récupérable
- **Occasion** : Pas de TVA si vendu par un particulier (régime de marge)
- **Professionnel à pro** : Livraison intracommunautaire, autoliquidation

## Nos conseils pour maximiser la récupération

1. **Privilégiez les VU** pour les besoins réels (livraison, chantier)
2. **Étudiez le DERIV VP** si vous avez besoin d'un SUV ou break
3. **Passez à l'électrique** pour cumuler TVA récupérable + bonus + exonération TVS
4. **N'oubliez pas le carburant** : déclarez la TVA chaque trimestre
