## Créer son compte et configurer la recherche

### Étape 1 : Choisir la bonne version du site

AutoScout24 existe en versions nationales : autoscout24.de (Allemagne), autoscout24.it (Italie), autoscout24.be (Belgique), autoscout24.fr (France)...

**Astuce** : Utilisez **autoscout24.com** qui agrège les annonces de tous les pays. Vous pouvez filtrer par pays, élargir ou restreindre votre périmètre géographique.

### Étape 2 : Maîtriser les filtres avancés

| Filtre | Utilisation optimale |
|---|---|
| **Pays / Rayon** | Sélectionnez Allemagne + Belgique + Italie pour maximiser les résultats |
| **Prix** | Fixez votre budget max TTC (incluant les frais d'import estimés) |
| **Kilométrage** | 30 000 - 80 000 km = sweet spot en occasion |
| **Année** | 2-4 ans = meilleur rapport décote/état |
| **Vendeur** | Filtrez "Professionnel" pour plus de sécurité |
| **Motorisation** | Sélectionnez essence, diesel, hybride ou électrique |
| **Boîte** | Automatique si c'est un critère |

### Étape 3 : Activer les alertes

Créez des alertes par email pour être notifié dès qu'une annonce correspondant à vos critères est publiée. Les meilleures affaires partent en 24-48h — l'alerte vous donne un avantage critique.

## Comment évaluer une annonce

### Les signaux positifs

| Signal | Ce que ça indique |
|---|---|
| Nombre élevé de photos (15+) | Vendeur transparent |
| Description détaillée | Vendeur sérieux |
| Historique d'entretien mentionné | Véhicule bien suivi |
| "TÜV neu" (Allemagne) | CT récemment passé |
| Badge "vendeur certifié" | Professionnel vérifié par AutoScout24 |

### Les signaux d'alerte

| Signal | Risque |
|---|---|
| 2-3 photos seulement | Cache des défauts |
| "Prix négociable" sans prix fixe | Souvent inflated starting price |
| Description vague ou traduite automatiquement | Arnaque possible |
| Prix 30%+ sous le marché | Trop beau pour être vrai |
| Vendeur ne veut pas fournir le VIN | Cache l'historique |

## Négocier sur AutoScout24

### La communication

La plupart des vendeurs professionnels allemands parlent anglais. Pour les particuliers, utilisez DeepL (plus précis que Google Translate) pour rédiger vos messages.

**Template de premier contact :**

> "Bonjour, je suis intéressé par votre [modèle] réf. [n° annonce]. Pourriez-vous me communiquer : 1) le numéro VIN complet, 2) l'historique d'entretien, 3) le rapport TÜV/CT, 4) votre meilleur prix pour un achat rapide avec virement immédiat ? Merci."

### La stratégie de prix

1. Identifiez le **prix moyen** du modèle sur AutoScout24 (fonctionnalité "évaluation du prix")
2. Proposez **10-15% en dessous** du prix affiché
3. Justifiez : "J'ai trouvé le même modèle à [prix inférieur] chez un autre vendeur"
4. Proposez le **paiement immédiat par virement** comme levier

## Sécuriser l'achat à distance

### Vérifier le véhicule sans se déplacer

| Action | Outil | Coût |
|---|---|---|
| Vérifier le VIN (historique) | CarVertical / AutoDNA | 15-30€ |
| Demander le rapport TÜV/CT | Au vendeur (gratuit) | 0€ |
| Inspection par un tiers | DEKRA / TÜV / AA | 150-300€ |
| Appel vidéo avec le vendeur | WhatsApp / Zoom | 0€ |

### Le paiement sécurisé

**Pour les professionnels :** Virement SEPA après signature du contrat de vente. Les concessionnaires allemands, belges et italiens sont habitués aux acheteurs étrangers.

**Pour les particuliers :** Privilégiez un virement avec séquestre (possible via certaines plateformes) ou payez à la livraison. JAMAIS de Western Union, Moneygram ou crypto.

| Retrait sur place | Billet avion + péages | 1 jour |

## FAQ — Questions fréquentes

### AutoScout24 est-il fiable ?

La plateforme elle-même est fiable et vérifiée (2M+ annonces, 18 pays). Cependant, les vendeurs individuels ne sont pas tous vérifiés de la même manière. Les vendeurs "certifiés" ont été vérifiés par AutoScout24. Pour les particuliers, appliquez les vérifications standard : VIN, historique, pièces d'identité. Les arnaques existent mais sont rares sur les vendeurs professionnels.

### Peut-on acheter directement sur AutoScout24 ?

AutoScout24 est une plateforme de mise en relation, pas de vente directe. La transaction se fait entre vous et le vendeur. AutoScout24 ne garantit pas la transaction. Vous pouvez cependant utiliser les évaluations et avis sur les vendeurs professionnels pour choisir un partenaire fiable.

### Quelle est la différence entre mobile.de et AutoScout24 ?

mobile.de est principalement allemand (1,4M d'annonces, 98% en Allemagne). AutoScout24 est paneuropéen (2M+ d'annonces, 18 pays). Pour un achat en Allemagne exclusivement, mobile.de offre un stock plus large. Pour chercher dans plusieurs pays simultanément, AutoScout24 est supérieur. Les deux plateformes sont fiables et utilisées par les professionnels.
